Part 0 Exercises

Practise what you've learned about C# data types and data structures. Write the code, run it, reflect on the output.

Data Types Exercises

Exercise A.1 — Pick the Right Type

For each of the following pieces of data, choose the most appropriate C# type and explain why:

  • A person's age in years
  • The price of a product (e.g., £29.99)
  • Whether a user is logged in
  • A user's email address
  • The population of Earth (approximately 8 billion)
  • The letter grade of a student (e.g., 'A', 'B', 'C')
  • The temperature outside in Celsius with one decimal place
Exercise A.2 — Interactive: Type Identification

What C# type would you use to store the value 3.14159 when you need maximum decimal precision (e.g., financial calculation)?

Exercise A.3 — Value vs Reference

Without running the code, predict the output of each snippet. Then run them to check: 

// Snippet 1
int x = 5;
int y = x;
y = 100;
Console.WriteLine(x);

// Snippet 2
int[] arr1 = { 1, 2, 3 };
int[] arr2 = arr1;
arr2[0] = 99;
Console.WriteLine(arr1[0]);

Were the results what you expected? Explain why each behaves the way it does.

Exercise A.4 — Type Conversion Challenge

Write a small C# program that:

  1. Asks the user to enter their age as a string.
  2. Uses int.TryParse to safely convert it to an integer.
  3. If the conversion succeeds, prints: "In 10 years you will be X years old."
  4. If the conversion fails, prints: "That doesn't look like a valid age."
Exercise A.5 — The Floating-Point Trap

Run the following code and explain the result: 

Console.WriteLine(0.1 + 0.2);
Console.WriteLine(0.1m + 0.2m);

Why are the results different? When would you use decimal over double in a real application?

Data Structures Exercises

Exercise B.1 — Interactive: Choose the Structure

You are building a task-management system. Users submit tasks and the system processes them in the order they arrive. Which data structure should you use?

Exercise B.2 — Word Frequency Counter

Write a program that counts how many times each word appears in a sentence. Use a Dictionary<string, int>. For the sentence "the cat sat on the mat and the cat", the output should show: the: 3, cat: 2, sat: 1, on: 1, mat: 1, and: 1.

Hint: split the sentence with sentence.Split(' '), then loop through the words and either add them to the dictionary or increment their count.

Exercise B.3 — The Undo Stack

Build a simple text editor simulation using a Stack<string>:

  1. Start with an empty document (empty string).
  2. Each "type" operation pushes the new document state onto the stack.
  3. Each "undo" operation pops the last state off the stack.
  4. Simulate: Type "Hello", Type "Hello World", Undo, Undo — and print the document state after each step.
Exercise B.4 — Deduplication with HashSet

You have a list of email addresses with duplicates. Use a HashSet<string> to remove all duplicates and then print the unique emails. Start with this list: 

var emails = new List<string>
{
    "alice@example.com", "bob@example.com", "alice@example.com",
    "carol@example.com", "bob@example.com", "david@example.com"
};

How many unique emails are there? Use new HashSet<string>(emails) to construct the set from the list in one line.

Exercise B.5 — Structure Performance Thought Experiment

You are building a system that checks whether a user ID is on a blocklist. The blocklist has 1,000,000 entries. You need to check membership thousands of times per second. Which structure should you use — List<int> or HashSet<int>? Explain why, referencing the performance characteristics of each.
